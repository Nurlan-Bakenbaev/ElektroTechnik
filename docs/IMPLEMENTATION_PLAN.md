# Incremental rebuild plan

## Reference release

- Discovery: current dependencies, hash routes, local persistence, formula assets, all thirteen module structures and existing tests inspected. Defects documented in `AUDIT_REPORT.md`.
- Product architecture: scoped instrument design, pure SI calculation layer, versioned activity reducer, shared unit-aware grader, validated lesson data.
- Reference implementation: complete Ohm learning sequence, model-based diagram/graph/meters/table, 13 practice checks, optional reference material and existing final topic quiz.
- Validation: deterministic physics and boundary tests; browser walkthrough, restoration, denied storage, mobile overflow, reduced motion and real screenshots. Results belong in `QUALITY_ASSURANCE.md`.

## Subsequent module migrations

1. Current/voltage/resistance: add instrument-connection tasks and consistent charge-flow explanations.
2. Circuit types: guided node/branch measurements and current/voltage conservation, then mixed resistor networks.
3. Energy/power/efficiency: measurement intervals, Wh/kWh conversion and power-loss balance.
4. Capacitor: connect the tested RC model to a time-domain graph and include initial conditions.
5. Fields/magnetism: explicit vector models, geometry and model boundaries, then induction.

Each migration needs a validated data contract, topic-specific experiment, meaningful independent tasks and passing browser checks before the module is described as complete. Preserve old references and profile IDs. Do not fabricate new modules to meet a quantity target.

## Platform backlog

Consolidate legacy CSS, audit remaining formula-image semantics, extend guided-session export/import, separate final exam feedback timing, add automated screenshot baselines and broader assistive-technology checks. PDF export and a second theme are optional follow-ups, not hidden promises in this release.
